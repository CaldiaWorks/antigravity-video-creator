# API Documentation

## REST APIs
The current project provides no REST APIs as it is an offline build-to-video application.

## Internal APIs
### Slide Components (e.g., Slide01_Hero)
- **Methods**: Implemented as React Functional Components (FC).
- **Parameters**: Currently static or accepting simple props like colors and title text via Remotion configuration.
- **Return Types**: ReactNode (specifically JSX elements for Remotion).

## Data Models
There are no complex internal data models, as data is mostly static text within the Presentation layers or simple props passed from Root Compositions.

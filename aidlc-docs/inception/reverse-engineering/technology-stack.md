# Technology Stack

## Programming Languages
- TypeScript - v5.9.3 - Type-safe programming language across all React code.
- CSS - Styling language via Tailwind.

## Frameworks
- React - v19.2.3 - Core UI library.
- Remotion - v4.0.409 - React to Video generation framework.
- Tailwind CSS - v4.1.18 - Utility-first styling framework.

## Infrastructure
- Node.js - Local environment for executing Remotion builds.

## Build Tools
- npm - Dependency management.
- Webpack - Internal bundler configured exposed by Remotion.
- PostCSS - CSS processor for Tailwind integration.

## Testing Tools
- No testing framework explicitly defined in `package.json`.

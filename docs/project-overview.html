Antigravity Video Creator

React + Remotion によるプログラム駆動型の動画生成エンジン

React 19 Remotion 4 TypeScript Tailwind CSS

作成できる動画

5種類のコンポジションが登録されており、用途に応じた動画を生成できます

AI Governance Video

AIガバナンスをテーマにした8シーン構成のナレーション付き動画。サイバーパンク風の背景にBGMとシーンごとの音声を同期再生します。

1080 x 1920 30fps ~2分 縦型

Workflow Video

4フェーズのワークフローを紹介する7枚構成のプレゼン動画。ヒアリングからビルドまでの流れを視覚的に伝えます。

1920 x 1080 30fps 35秒 横型

Avatar Test

音声に反応する2Dアバターのテスト動画。リップシンク、まばたき、呼吸アニメーション、バウンスエフェクトを確認できます。

1080 x 1080 30fps 15秒 正方形

Avatar コンポーネント

音声データからリアルタイムにアニメーションを生成する再利用可能なコンポーネント

4ステート画像切り替え

veadotube mini の4状態構造に準拠し、idle / speaking / blinkIdle / blinkSpeaking の画像を音声データとフレーム位置から自動選択します。


3種のアニメーション

呼吸：サイン波でY軸を最大7%伸縮。バウンス：音量の急激な立ち上がりで最大15%拡大。まばたき：秒ごとに30%の確率で4フレーム間発動する決定論的ロジック。

プロジェクト構成

Remotion の Composition をルートとし、スライドとシーンを子要素として構成

使い方

Remotion の標準コマンドでプレビュー・レンダリングが可能です

1. Install

npm install

2. Preview

npx remotion studio

3. Render

npx remotion render
